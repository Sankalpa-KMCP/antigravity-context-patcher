# Documentation Screenshots

This directory stores visual documentation and status bar interface captures for the Antigravity Token Monitor and Context Patcher.

## Recommended Visuals

1. `statusbar-pending.png`: Shows the active pending state during generation (`⚡ 222.3k+ / 960k | pending`).
2. `statusbar-exact.png`: Shows the completed turn state with calculated usage percentage (`⚡ 217k / 960k | 22.6%`).
3. `statusbar-stale.png`: Shows session recycle state (`⚡ 142.1k+ | model 256k | awaiting current-session turn`).
4. `statusbar-disconnected.png`: Shows disconnected state when the Language Server process is closed (`⚡ Token Monitor: disconnected`).
